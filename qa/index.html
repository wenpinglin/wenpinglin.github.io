入户服务
Q 用户问"你们怎么是电信的？"怎么回？ ▼

三步应对：亮身份 → 说缘由 → 转服务

"对，我们是电信的，同时我们也是智慧社区志愿者。因为单元门门禁是我们公司承建的，所以需要我们帮忙给居民录入信息和服务。您看，这是我们的工作证（展示工牌）。现在帮您录入门禁信息，大概需要10分钟，录入后您就可以刷脸开门了。"

不要遮遮掩掩不承认，也不要一上来就介绍电信业务，要大方承认但强调"服务"属性。
Q 用户问"为什么要入户？"怎么回？ ▼

三步应对：说刚需 → 说服务 → 说安全

"师傅/阿姨，小区所有居民都要录入门禁信息，不录的话后期会非常不方便，刷脸开不了门。另外，我们还提供免费的家庭网络检测服务，帮您检测家里WiFi信号好不好、有没有死角。您看明天上午或下午哪个时间方便？"

用"免费服务"作为入户理由，降低抵触。
Q 用户不开门怎么应对？ ▼

"今天是社区服务的最后一天了，明天我们就去别的小区服务了。"

"我们就在小区里，过来很快，大概5分钟就到。"

也可请物业管家协助敲门，或后续电话复约。
Q 为什么要录入人脸？用户有顾虑怎么办？ ▼

"小区所有居民都要录入门禁，录完以后您才可以刷脸进入单元门，不录的话后期会非常不方便，这也是为了您的安全。"

如果用户担心隐私：

"我们的系统是按照公安标准建设的，数据本地化部署，不会上传到外网。这是我们的安全等级备案证明（展示）。"

Q 为什么要等审核？用户嫌慢怎么办？ ▼

"为了防止非本楼栋人员录入人脸，我们的审核人员与物业一起逐个把关，确保信息一致，请您稍等一下。这个档口我刚好给您演示一下如何开门。"

审核等待期间正是做智屏演示的最佳时机！发暗号给后台控制审核节奏：
"1栋101抓紧审核" → 营销概率低，5分钟内审核完
"1栋201请审核" → 营销概率高，20分钟内审核完
Q 已经有人脸信息的存量小区，用户问为什么要重新审核？ ▼

"因为门禁更细了，大门是小区的都可以进入，但单元楼要确认下，只有您这个单元楼的才能进入，所以需要重新审核确认。"

反复强调"这是升级服务"、"新装了单元楼门禁"，让用户感觉"有新的价值"。

Q 入户五步法的顺序是什么？ ▼

服务 → 演示 → 测速 → 组网 → 笔算

  • 第1步 服务（5分钟）：注册公众号、录门禁人脸，趁机了解家庭网络消费情况
  • 第2步 演示（8分钟）：智屏"1+4"场景体验，至少演示3个场景
  • 第3步 测速（3分钟）：3-5个点位测速，挖网络痛点
  • 第4步 组网（2分钟）：手绘户型图，标注盲区，提供FTTR方案
  • 第5步 笔算（5分钟）：合账付费对比算账 + 千兆城市补贴
千万不要一进门就推销！先服务，再营销。服务时间≥20分钟。
产品功能
Q 门禁有哪些开门方式？ ▼

业主开门：刷脸开门（0.5秒识别，不用带卡带钥匙）

访客开门（三种方式）：

  • 微信公众号"一键开门"（小屏，看不到访客视频）
  • 智屏对讲开门（大屏，能看见访客视频，访客按房号自动响铃）
  • 手机远程开门（在外地也能给家人开门）

另外还支持IC卡开门、二维码开门、密码开门。

Q 智屏"1+4"场景是什么？ ▼

"1" = 开门禁（核心卖点）

"4" = 四大扩展场景：

  • AI看电视："小翼管家，我要看中央五套" → 70+频道+7天回看+爱优腾N选1
  • AI打电话："小翼管家，给妈妈打视频电话" → 视频通话+紧急呼救（"小翼管家，救命"）
  • 看监控："小翼管家，打开7天云回看" → 远程看家+云回看
  • 电子相册：照片轮播，屏保时自动播放
入户前必须提前绑定：智屏绑定梯口门禁、翼视界已受理、翼家智话已设定、云相册已上传照片、云回看已测试。
Q 智屏和手机开门有什么区别？怎么跟用户说？ ▼
  • 屏幕大小：智屏大屏看得清，手机小屏
  • 看见访客：智屏可以看见访客视频，手机一键开门看不到
  • 主动通知：访客按房号智屏自动响铃，手机需要业主主动打开操作
  • 语音开门：智屏喊一声"小翼管家，开门"就行，不用动手
Q 翼视界在异网环境下无法演示怎么办？ ▼

翼视界需要电信网络才能使用。在异网环境下，必须连接CP的手机热点来演示。

入户前务必提前测试好热点连接，避免现场演示失败。
Q 紧急呼救功能怎么演示？ ▼

语音："小翼管家，救救我" 或 "小翼管家，救命"

实现效果：自动拨通预先设置的紧急联系人号码（最多5个，同时呼叫，第1个接起后其他自动挂断）。

入户前必须在小翼管家上提前绑定好紧急联系人，否则演示会失败！
营销转化
Q 笔算怎么算？合账付费的逻辑是什么？ ▼

第一步：算用户现有消费

  • 看电视（广电/IPTV）：18-22元/月
  • 视频会员（爱优腾）：25元/月
  • 监控摄像头：100-200元/台
  • 电子相册：450元/台
  • 合计：每月超35元 + 首次近千元

第二步：算智屏价值

办理天翼智屏相当于提供：两台电视观看账号（直播+点播+回看）、一部可视频的固话（每月送120分钟）、一个监控、一个家庭云盘（电子相册）、爱优腾会员每月可更换。

第三步：算千兆补贴

  • FTTR设备补贴：1主1子网关，价值1799元，两年维保
  • 线材补贴：网线换光纤线、组网设计费、工时费等，价值1000元+
  • 智能设备补贴：天翼智屏，价值600元
合账付费比分开买更省，而且有机会领取千兆城市补贴，设备材料免费领，套餐只需迁改。
Q 用户讲价怎么应对？ ▼

小技巧：先按标准版35元笔算，用户讲价后"向领导申请"最终按10元报价（新装用户），让用户感觉赚到了。

异网纯新装场景：做全家笔算，将门禁室内机/监控/看电视等费用都计入全家费用，然后将主套餐+智屏打包报价，例如229+10给用户报价239元。

Q CP组合角色怎么分工？ ▼

角色A（营销人员）：讲生活场景、挖需求、算账

角色B（智家工程师）：做演示、测网速、专业支持

配合口诀：A讲生活场景，B做技术演示；用户点头再推进，不点头就做服务

  • 工程师演示时，营销人员观察用户反应，寻找痛点信号
  • 营销人员挖痛点时，工程师补充技术细节
  • 营销人员笔算时，工程师支持数据

三大配合关键（杜绝推销感）：

  • A不夸产品，聊生活 — 不说"设备有N大功能"，说"您家老人孩子开门方便吗？"
  • B不抢话，只演示/测速 — 工程师是技术服务角色，用户问才开口，平时点头配合
  • 用户不点头，不提钱 — 不主动报价，只说"帮您查询免费领取"；无兴趣就测网速，绝不硬推
千万不要角色颠倒：工程师不要抢着推销，营销人员不要抢着演示设备。
Q 低意向用户和高意向用户怎么区分应对？ ▼

场景化分支流程：

完成步骤1-7（进门→录脸→开权限→辅导开门→智屏演示）后，根据用户反应走不同分支：

用户问价/感兴趣（高意向）：

  • 步骤8：查询"免费领取"可能 — "这个屏是跟梯口门禁配套的，我帮您查一下是否可以免费领取"
  • 步骤10：价值笔算 — 算综合账（家庭通讯+电视+门禁三合一），不报单品价格

用户无明显兴趣（低意向）：

  • 步骤9：免费网络测速服务 — "这次服务还有免费网络检测，我们工程师帮您诊断一下"
  • 测速过程自然聊网络/智屏价值，待用户松动后再进入步骤10
  • 5分钟快速通关，留后路，不纠缠
临场金句：挖痛点 — "您有没有碰上过亲戚在楼下等，您还没到家？" | 测速引子 — "家里网速好，这些智能设备才不卡顿" | 算账 — "通讯+电视+门禁三合一，比分开买划算太多"

异议处理
Q 用户说"我不需要/没兴趣" ▼

三步应对：共情理解 → 场景代入 → 降低门槛

"我理解，您可能觉得这个事跟您关系不大。不过师傅，您想想，以后快递上门、朋友来访，您在办公室或者外地，直接用手机就能给他们开门，不用跑上跑下，是不是挺方便的？而且今天主要是帮您开通门禁权限，免费的。那个智屏您可以先体验一下，觉得好再用，不好也不用勉强。"

不要一直强调"这个很好，您一定要办"，要用场景让用户自己意识到需求。
Q 用户说"太贵了" ▼

三步应对：拆解价值 → 对比支出 → 补贴促单

"大哥，我给您算笔账：您现在看广电电视要22块，爱奇艺优酷会员要25块，这就47块了。还不算您家监控、电子相册这些。我们这个智屏合账付费，电视、会员、监控、视频电话全包含，比分开买还省钱。而且现在有千兆城市补贴，FTTR设备、线材、工时费全免，价值3300块，这个月就截止了。"

Q 用户说"我再想想/商量一下" ▼

三步应对：探寻原因 → 更换决策人 → 制造紧迫

"没问题，买东西确实要慎重。方便问一下，您主要担心哪方面？是价格问题，还是怕用不好？"

"您爱人回来的时候，我们再上门给开通门禁，家里有老人小孩确实会更方便。不过这个千兆城市补贴这个月就截止了。您家里门禁还没录入，到时进出不方便，回来的时候联系下，我们再来开通。"

预留再入户机会！不要打电话给不在家里的人决策。
Q 用户说"我用不着这些功能" ▼

三步应对：反问挖掘 → 场景化演示 → 第三方证明

"师傅，您家有没有快递上门的情况？有没有老人或者小孩在家？"

（用户说有）→ 演示远程开门+可视对讲 → "隔壁201的业主刚才也办了，说用起来很方便。"

不要一次性介绍所有功能造成信息过载，先挖掘场景再针对性演示。
Q 用户问"为什么要演示？" ▼

"按厂家及物业建设的要求需要给您做个开门演示，让您了解升级后的新功能。无论您是否有意向配备智屏，均需完成演示动作。"

Q 用户说"我家网络挺好的" ▼

"刚才演示的时候您也看到了，视频有点卡顿。而且我们这次来主要是做门禁服务，网络检测是免费增值服务，顺便帮您看看。"

Q CRM受理分几步？ ▼

小区合作
Q 怎么选小区？"143"原则是什么？ ▼

"1"个有：小区有意愿（物业&业委会配合）

"4"个好：

  • 物业客情好 — 能配合安装、活动站台、公告通知
  • 物业与业主关系好 — 避免关系紧张的小区
  • 单元门关门好 — 门能关上，居民有门禁使用习惯
  • 单元门条件好 — 磁力锁、闭门器等零件仍可用

"3"个多：

  • 高层多 — 高层占比大于50%
  • 住户多 — 单个门禁可覆盖40-50户及以上，且异网用户多
  • 常住居民多 — 租户比例不超过30%
黄金窗口期：2000-2010年建成、12层以上、有物业、用刷卡门禁的高层住宅小区。
Q 四种合作商务模式怎么选？ ▼

模式1 · 对方全部投 — "大胆做"

  • 适用：老旧小区有改造需求，或物业/业委会要求一次性支付不接受分期
  • 方式：小微项目型，门禁+监控+综合布线整体方案，对方一次性支付
  • 优势：利润高，分局有项目收入

模式2 · 电信投设备+对方出网络费 — "放心做"

  • 适用：物业有需求但小区单元多，减轻前期资金压力
  • 方式：设备由电信成本投入，与物业签3年合同，物业每月付门禁网络费
  • 优势：物业前期零设备投入，双方长期合作

模式3 · 电信成本投单点突破 — "悠着做"

  • 适用：高价值小区，电信投入单元门禁获得独家入场机会
  • 方式：精选小区，单个门禁至少覆盖40户以上，电信门禁唯一且有关门，满足143原则
  • 避坑：必须在合同中明确"门禁唯一性"和"闭门要求"，合作前做好效益测算

模式4 · 代理商投入包区 — "一起做"

  • 适用：代理商有本地资源，愿意投入门禁设备
  • 方式：代理商投设备+负责建设及物业关系，电信提供网络+平台，双方按约定分成
  • 优势：代理商限时独家发展业务，合作共赢
无论哪种模式，电信出资的都必须确保门禁唯一性和关门启用，否则触客率会很低。
